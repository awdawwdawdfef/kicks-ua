Вхід в адмінку

Потрібен GitHub Personal Access Token з доступом до твого репозиторію. Токен зберігається тільки в цьому браузері та ніде більше.

Немає токену? Створи його тут: github.com/settings/personal-access-tokens/new

При створенні: обери "Only select repositories" → свій репозиторій → у Permissions постав "Contents: Read and write".
