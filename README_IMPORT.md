Admin Import (Easydrop → products.json)
======================================

Что это
-------
admin.html — простой клиентский админ-интерфейс для преобразования XML (например, easydrop supplier catalog) в products.json и записи этого файла в ваш репозиторий GitHub через GitHub API.

Функции
-------
- Загрузить XML файл (или указать URL — работает только если домен разрешает CORS).
- Указать параметры порогов и лимит.
- Сгенерировать products.json (структура: { generated_at, source, products: [...] }).
- Записать products.json в указанный репозиторий/ветку/путь (через GitHub API) — требуется PAT (Personal Access Token).

Где разместить
--------------
Положите admin.html в корень репозитория (или в admin/). Откройте его как страницу сайта (например, https://your.github.io/repo/admin.html) или локально (file://) — для записи в GitHub вам потребуется PAT.

Как пользоваться
----------------
1. Откройте admin.html в браузере.
2. Укажите либо URL XML, либо загрузите XML файл локально.
   - Если fetch по URL не работает — скорее всего домен блокирует CORS; в этом случае загрузите файл вручную.
3. Установите параметры:
   - owner/repo — ваш репозиторий (example: awdawwdawdfef/kicks-ua)
   - branch — ветка (например main)
   - path — куда сохранить файл (например site-content/products.json)
   - GitHub token — введите вручную (fine‑grained PAT с Contents: Read & write для репозитория).
4. Нажмите "Предварительный просмотр", посмотрите preview JSON.
5. Нажмите "Преобразовать и сохранить в репозитории".
6. Проверьте репозиторий — products.json появится/обновится.

Замечания по безопасности
------------------------
- Токен вводится вручную в поле и НЕ сохраняется в репозитории этим файлом. Никогда не коммитьте токен.
- Лучше создать Fine‑grained PAT с доступом только к конкретному репозиторию и только permission "Contents: Read & write".
- Если вы пользуетесь public machine, не храните токен в браузере.

Если CORS блокирует URL
-----------------------
- admin.html делает client-side fetch; если easydrop не отдаёт CORS заголовки, fetch будет блокироваться. Решение:
  - Скачайте XML локально и загрузите файл через поле "Загрузить XML".
  - Или используйте серверную обработку (GitHub Actions или ваш сервер) — при желании могу подготовить workflow/action.

{
  "generated_at": "...",
  "source": "easydrop",
  "products": [
    {
      "group_id": "19100792694610",
      "name": "...",
      "description": "...",
      "images": ["https://..."],
      "category": "...",
      "variations": {
        "S": { "qty": 5, "price": "1200", "status": "instock" },
        "M": { "qty": 0, "price": "1200", "status": "outofstock" }
      },
      "total_qty": 5,
      "imported_at": "..."
    }
  ]
}
